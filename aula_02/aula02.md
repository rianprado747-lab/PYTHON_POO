#### Grandes vantagens da OO, a Sigla COMERN.
1. __Confiável__: todo o sistema orientado a objeto é confiável.
O isolamento entre as partes gera algo mais seguro. Ao alterar uma das partes, nenhuma outra é afetada.


2. __Oportuno__: Ao dividir tudo em partes, cada uma delas pode ser desenvolvida em paralelo.


3. __Manutenível__: Atualizar é mais fácil. Uma pequena alteração vai beneficiar todas as partes relacionadas.


4. __Extensível__: Um sistema não deve ser estático. Tudo deve mudar e crescer para permanecer útil.


5. __Reutilizável__: Objetos criados para um sistema podem ser aproveitados em outros sistemas.


6. __Natural__: Mais fácil de entender. Maior atenção às funcionalidades do que aos detalhes de implementação.
