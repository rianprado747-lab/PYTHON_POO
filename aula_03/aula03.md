## Classes, objetos, Atributos, etc..

* #### O que é Objeto? 
    Um objeto é uma unidade de código independente que junta dados (atributos) e ações (métodos).
    Ele funciona como uma representação digital de algo do mundo real ou de um conceito abstrato, 
    sendo criado a partir de um modelo chamado classe.  
    É uma coisa material ou abstrata que é feita a partir de uma classe e pode ser descrita por meio de seus
    atributos, métodos e estado atual.
* #### O que é uma classe?    
    Uma classe na programação orientada a objetos (POO) é um modelo ou planta que define as 
    características (atributos) e os comportamentos (métodos) que os objetos criados a partir dela 
    vão possuir. Ela serve como um molde para gerar instâncias reais.
    Para criar uma classe é necessário três coisas.
  1. Nome da Classe.
  2. __Atributos:__ Características que a classe vai ter. 
  3. __Métodos:__ Coias que a classe pode fazer.
* #### O que é uma Instância?     
    Instanciar é seguir o padrão que foi definido na classe para criar o objeto.
* #### O que é estado?
    É o conjunto de valores dos atributos do objeto que podem sofrer alteração com o passar do tempo.
* #### O que é Objeto Abstrato?
    Modelo genérico que define regras e comportamentos básicos, mas não pode ser criado diretamente.
    Ele serve como base para outras classes preencherem os detalhes que faltam. 
    __EXEMPLOS__
    * Uma consulta marcada no médico.
    * Um processo de venda.
    * Um compromisso ou reunião.
    * Uma aula na faculdade.
    * Uma transação bancária.
    * Uma reserva de voo.
    * Um erro do sistema.

_Um objeto é uma instância de uma classe_
